# システム概要

## 目的

このシステムは、事業者から届いた勤務依頼とスタッフの勤務可能時間やスキルを管理し、勤務の割り当てを支援するためのシステムである。

Ruby合宿では、このリポジトリを各チームが共通基盤として利用する。

## 主なデータ

### 事業者

`Business`で事業者の名称、担当者、連絡先、利用状態などを管理する。

1つの事業者は複数の勤務依頼を持つ。

### 勤務依頼

`WorkRequest`で勤務のタイトル、開始時刻、終了時刻、必要人数、必要スキル、状態などを管理する。

勤務依頼は1つの事業者と1つの必要スキルに属する。

### スタッフ

`StaffMember`でスタッフの氏名、在籍状態、備考などを管理する。

スタッフは勤務可能時間、スキル、勤務割り当てを複数持つことができる。

### 勤務可能時間

`Availability`で、スタッフが勤務可能または勤務不可能な時間帯を管理する。

開始時刻より終了時刻が後になる必要がある。

### 勤務割り当て

`Assignment`で勤務依頼とスタッフの組み合わせを管理する。

同じ勤務依頼へ同じスタッフを重複して割り当てることはできない。

### スキル

`Skill`で業務に必要なスキルを管理する。

`StaffSkill`によってスタッフとスキルを関連付ける。

### 変更記録

`ChangeEvent`で勤務依頼、勤務可能時間、勤務割り当てなどに対する変更内容を記録する。

変更記録には、変更対象、操作内容、発生日時、確認状態、記録元などを保存する。

## 現在の確認画面

現在、次の画面を共通の確認画面として利用できる。

- 勤務依頼一覧
- 勤務依頼詳細
- スタッフ一覧
- 変更記録のデバッグ画面
- 静的JSONとブラウザ保存の確認画面

## 主なURL

| URL | 内容 |
|---|---|
| `/` | 勤務依頼一覧 |
| `/work_requests` | 勤務依頼一覧 |
| `/work_requests/:id` | 勤務依頼詳細 |
| `/staff_members` | スタッフ一覧 |
